# Troubleshooting Guide — LexTech

## I cannot log into my account

### Reason 1: Wrong password
If you forgot your password:
1. Go to www.lextech.com/login
2. Click "Forgot Password"
3. Enter your email address
4. Check your email for a reset link
5. Click the link and create a new password
The reset link expires after 30 minutes.

### Reason 2: Account locked
Your account gets locked after 5 failed login attempts.
To unlock it, wait 15 minutes and try again, or contact support@lextech.com.

### Reason 3: Email not verified
If you just created your account, check your inbox for a verification email.
Check your spam folder if you do not see it.

## My dashboard is loading slowly

This usually happens because of one of these reasons:
- Too many browser tabs open — close unused tabs
- Slow internet connection — check your connection speed
- Browser cache is full — clear your browser cache and cookies
- Outdated browser — update your browser to the latest version

To clear cache in Chrome: Settings → Privacy → Clear Browsing Data → Cached Images and Files

## I cannot upload a file

LexTech supports these file types: PDF, PNG, JPG, DOCX, XLSX, CSV
Maximum file size is 25MB on Free plan and 100MB on Pro and Enterprise plans.

If your upload fails:
1. Check the file size is within your plan limit
2. Check the file type is supported
3. Try a different browser
4. If the problem continues, email support@lextech.com with error code ERR_UPLOAD_FAIL

## Two-factor authentication (2FA) is not working

If you are not receiving your 2FA code:
1. Check that your phone number is correct in Account Settings
2. Wait 60 seconds and request a new code
3. Check your spam folder if using email 2FA
4. If using an authenticator app, make sure your phone clock is synced

To reset 2FA completely:
1. Contact support@lextech.com
2. Provide your account email and employee ID
3. Support will verify your identity and reset 2FA within 2 hours
